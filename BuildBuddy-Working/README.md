# BuildBuddy — complete PC builder

This folder contains the complete website source.

## Main files
- `index.html` — page structure
- `style.css` — website styling
- `script.js` — main browser application
- `js/` — component catalog, compatibility and FPS logic, Three.js PC model modules, textures, and price-feed import

## Run on Windows
1. Extract the whole ZIP to a normal folder.
2. Install Python 3 if it is not already installed.
3. Double-click `start-windows.bat`.
4. Open http://localhost:8000 in your browser.

## Run on macOS / Linux
Run `./start-mac-linux.sh` from this folder, then open http://localhost:8000.

Do not double-click `index.html` directly. Browsers block JavaScript modules on local `file://` pages. The included launcher starts a local web server so the modules load correctly.

## 3D preview
The PC case, motherboard, cooler, RAM, graphics card, cabling, and fans are generated by Three.js modules in `js/`. The preview uses a reflection environment and interior fill lights to keep components visible as the camera rotates. The Three.js library and OrbitControls are loaded from jsDelivr, so the browser needs internet access for the live 3D viewer. Fans animate continuously; use the Fan speed control to stop or speed them up.

The catalog includes 14 dedicated graphics-card options and 12 case options, with fit limits checked against the selected build.

## Prices and performance
Built-in prices are illustrative reference estimates in BRL, not live retailer quotes. Import a validated monthly JSON price file in the price panel to replace matching catalog estimates. FPS numbers are approximate planning ranges and are not benchmark guarantees.
